# Apply to selected jobs

Resolve the kit root three directories above this skill. Read `AGENTS.md`, the
selected private config/profile, [applications](../../../docs/applications.md),
[browser runbook](../../../docs/browser.md), and [tracking](../../../docs/tracking.md).

Check scope, exact job identity, duplicates, live availability, referral holds,
and configured filters. Reuse the reviewed master; change only supported skills
when useful. Freeze and verify any new PDF version before attachment. Preserve
submitted versions and replace stale attachments on pending forms.

The main agent owns all browser operations and tracker writes. If a reviewer is
requested, give a second agent the posting, candidate evidence, PDF version, and
captured form details. It prepares/checks answers but never controls tabs. Report
when independent review is unavailable rather than claiming it occurred.

Check every job and school after parsing and again after saving. Paste the
registered dash/newline role descriptions exactly. Resolve factual gaps from
saved evidence or the user; never guess legal history, eligibility, or methods.
Confirm candidate account identity and preserve referral evidence.

Follow the user's final-submit preference and current tool rules. Hand off
credentials, CAPTCHA, agreements, or assessments when required. Verify success
before recording Applied. Do not infer submission from a closed tab or a click.
Record receipts and synchronize the tracker after each outcome. On uncertain
results, inspect status before retrying; do not submit twice to test the site.
