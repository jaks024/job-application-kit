# Search jobs

Resolve the kit root three directories above this skill. Read `AGENTS.md`, the
selected private config/profile, [search](../../../docs/search.md), and
[tracking](../../../docs/tracking.md). If no workspace is selected, use setup.

Complete the broad coverage matrix on the first pass, including adjacent roles,
acceptable geography, industries, enabled internships, and catch-up windows.
Do not wait for the user to request a wider search. Honor explicit narrow scope.
Use available supported web/browser tools; report unavailable sources honestly.

Verify employer evidence, keep posting dates separate from discovery dates,
retain unknowns, and apply configured filters. Preserve original referral URLs
privately. Check complete active/archived tracker history and local receipts.
Use stable requisition identity; titles alone are insufficient for deduplication.

The main agent owns browser and tracker writes. Delegate public-source research
only when authorized, without model overrides by default. Before the shortlist,
finish accessible pending cells or report exact blockers and continuations.
Save coverage and evidence privately, sync authorized tracker changes, and verify.

Return new/updated counts, prioritized roles with evidence and gaps, exclusions,
duplicates, and coverage limitations. This skill does not authorize uploads,
applications, accounts, employer messages, or schedules.
