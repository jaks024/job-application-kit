# Attribution and export scope

This kit generalizes an agent-assisted job-search and application workflow.
It contains no candidate resumes, profiles, screening answers, application
history, tracker destinations, account records, screenshots, or browser state.
The initial distribution is a clean export with fresh Git history.

`tools/verify_pdf.py` is adapted from
[MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search),
copyright 2026 Mads Lorentzen, under the MIT License included in `LICENSE`.
It performs PDF text-layer and page-count checks. The original framework also
informed the workflow; candidate-specific instructions and upstream personal
templates were not copied into this distribution.

The other tools and generalized documentation in this distribution are provided
under the same MIT terms, copyright 2026 Job Application Kit contributors.
No affiliation with job boards, employers, Notion, or AI agent vendors is implied.
